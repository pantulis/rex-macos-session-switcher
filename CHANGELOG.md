# Changelog

## 0.1.0

First release.

- Native AppKit popup for switching Rex sessions, bound to ⌘E.
- Sessions ordered by recent use, opening on the previous session.
- Agent status (working, blocked, done, error) on each row.
- Per-session actions: go to, rename, new tab, copy ID, close with confirmation.
- New Session entry; typed text becomes the new session's name.
